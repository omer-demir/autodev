# Product documentation

This pack describes Autodev as implemented in the repository on October 6, 2026.

| Document                                      | Audience                           | Purpose                                                       |
| --------------------------------------------- | ---------------------------------- | ------------------------------------------------------------- |
| [Features and how-to](features-and-how-to.md) | Developers, operators, evaluators  | Product capabilities and step-by-step workflows               |
| [Product roadmap](roadmap.md)                 | Product and engineering leadership | Outcomes, sequencing, measures, and non-goals                 |
| [Elevator pitch](elevator-pitch.md)           | Sales, partners, executives        | Reusable one-line, 30-second, and two-minute pitches          |
| [Elevator pitch deck](elevator-pitch-deck.md) | Presenters and decision makers     | Portable Markdown slide deck with speaker notes               |
| [Market research](market-research.md)         | Product strategy and go-to-market  | Competitive landscape, customer needs, positioning, and risks |
| [Technical drawings](../diagrams/README.md)   | Architects and platform engineers  | Editable Draw.io architecture sources                         |

Product claims are divided into three states:

- **Implemented**: represented in code and exercised by the current application.
- **Optional**: implemented but requires operator configuration or external infrastructure.
- **Roadmap**: proposed work, not a current product capability.
